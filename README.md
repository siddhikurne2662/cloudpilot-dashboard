# CloudPilot

CloudPilot is a cloud workflow automation platform designed for managing and executing infrastructure workflows using n8n and Supabase. It provides secure credential storage, workflow management, execution tracking, and a modern dashboard for monitoring cloud automations across multiple providers.

---

## Features

- User authentication with Supabase Auth
- Workflow creation and execution
- Real-time execution monitoring
- Workflow template marketplace
- Secure encrypted credential management
- Multi-cloud support for AWS, GCP, Azure, and Kubernetes
- Execution history and timeline tracking
- Responsive dashboard UI
- Search and filter functionality
- Settings and profile management

---

## Tech Stack

Frontend:
- HTML5
- CSS3
- Vanilla JavaScript

Backend:
- Node.js
- Express.js

Database:
- Supabase (PostgreSQL)

Workflow Engine:
- n8n

Authentication:
- Supabase Auth

Security:
- AES-256-GCM encryption
- JWT authentication
- Row-Level Security (RLS)
